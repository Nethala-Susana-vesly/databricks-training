# Employee Database SQL Queries

This assignment contains basic SQL queries performed on the `Employees` table. The queries cover different SQL concepts such as:

💠 SELECT statements
💠 WHERE conditions
💠 Aggregate Functions (`SUM`, `AVG`, `COUNT`, `MAX`, `MIN`)
💠 GROUP BY and HAVING clauses
💠 ORDER BY and LIMIT
💠 DISTINCT keyword
💠 Logical Operators (`AND`, `OR`, `NOT`)
💠 IN, BETWEEN, and LIKE operators

The assignment helps in understanding how to retrieve, filter, sort, and analyze employee data using SQL queries.
