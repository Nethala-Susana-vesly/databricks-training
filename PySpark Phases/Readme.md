# 🚀 SQL to PySpark Learning Journey

## 📌 Overview

This repository showcases my hands-on learning journey in **SQL, PySpark, Spark SQL, ETL Pipelines, and Business Analytics** using Apache Spark. Through multiple phases, I explored data processing, transformation, business analytics, and customer segmentation using real-world sample datasets.

---

## 🛠️ Technologies Used

* Python 3.8
* PySpark 3.5.5
* Spark SQL
* Apache Spark
* Spark Playground

---

## 📂 Datasets

* customers.csv
* sales.csv
* products.csv
* products.json
* organizations.orc
* titanic.parquet

---

## 📚 Project Phases

### 🔹 Phase 2 – SQL to PySpark

* Converted SQL queries into PySpark DataFrame operations.
* Performed joins, filtering, sorting, and aggregations.
* Generated customer and sales insights.

### 🔹 Phase 3 – ETL Pipeline

* Built an Extract, Transform, Load (ETL) workflow.
* Worked with CSV, JSON, ORC, and Parquet files.
* Applied data cleaning, transformations, and reporting.

### 🔹 Phase 4 – Business Pipeline & Analytics

* Cleaned and processed customer and sales data.
* Generated business reports including daily sales, city-wise revenue, repeat customers, top customers, customer segmentation, and final reporting tables.

### 🔹 Phase 4A – Bucketing & Segmentation

* Implemented Gold, Silver, and Bronze customer segmentation.
* Explored quantile-based segmentation, Bucketizer, and Window Functions for customer analysis.
